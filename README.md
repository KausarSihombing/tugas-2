# Dokumentasi Rangkuman Git dan Markdown

Selamat datang! Dokumen README ini merupakan pengantar yang menjelaskan isi dari file catatan/rangkuman materi Git dan Markdown.

**Dibuat oleh:** Kausar Sihombing

## Tentang Rangkuman Ini
File rangkuman utama berisi catatan komprehensif yang membahas konsep dasar **Version Control System (VCS)**, penggunaan **Git** secara praktis, serta panduan penulisan sintaks **Markdown**. Catatan ini disusun sebagai referensi atau *cheatsheet* untuk memahami bagaimana cara melacak perubahan, mengelola versi, dan berkolaborasi dalam proyek perangkat lunak.

## Topik Utama yang Dibahas
Di dalam file rangkuman tersebut, Anda akan menemukan penjelasan detail mengenai topik-topik berikut:

1. **Pengantar Version Control**
   - Penjelasan tentang pelacakan (mengetahui setiap perubahan) dan pengelolaan data dari waktu ke waktu.
   - Perbandingan jenis-jenis VCS (Lokal, Terpusat/Client-Server, Terdistribusi).
 2. **Mengenal Git**
   - Definisi Git sebagai VCS terdistribusi yang *open source*.
   - Kegunaan utama Git, seperti pelacakan riwayat, kolaborasi jarak jauh, hingga *branching* dan *merging*.

3. **Perintah Dasar Git**
   - Langkah-langkah menginisiasi (`git init`) dan menyalin repository (`git clone`).
   - Penjelasan 4 status file dalam Git: *untracked, unmodified, modified,* dan *staged*.
   - Cara menyimpan perubahan (*commit*) dengan pesan tertentu.

4. **Membatalkan dan Melihat Riwayat Perubahan**
   - Cara membatalkan perintah tertentu (*undo*) menggunakan `git reset`.
   - Perintah untuk meninjau riwayat *commit* (`git log`, `--oneline`, `--graph`).

5. **Bekerja dengan Remote Repository**
   - Menghubungkan repository lokal ke server jarak jauh.
   - Daftar perintah esensial seperti `git remote`, `git clone`, dan `git push`.
 6. **Panduan Markdown**
   - Sintaks dasar untuk menulis dokumentasi seperti tata cara membuat judul (*heading*), gaya teks (tebal, miring, dicoret), dan daftar (*list* / *bullet points*).
